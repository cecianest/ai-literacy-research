내 연구 차별화 방안

차별화 축기존 연구와 겹치는 부분제안하는 구체적 설계
교수요소 분리모델 만들기·시험·개선·성찰은 기존 연구에도 포함공통 기초학습 후 ‘학습자료 개선’과 ‘테스트 자료 설계’를 같은 시간 동안 운영. 두 조건의 활동 기록으로 실제 차이 확인.
평가 대상 분리자기 모델의 성능이나 완성도는 데이터 수·제작 능력의 영향을 함께 받음두 집단 모두 학습하지 않은 동일한 모델을 평가. 제한된 시험 횟수 안에서 어떤 사례를 선택하고 어떤 약점을 발견하는지 측정.
비판적 사고의 수행화성찰·태도·포괄적인 검사 결과만으로 실제 검증 행동을 충분히 설명하기 어려움오류 가설 → 시험 조건 선택 → 증거 기록 → 원인 설명 → 판단 수정의 수행을 평가. 일반적 비판적 사고와 AI 맥락의 검증 수행을 구별해 명명.
새로운 과제로의 전이수업에서 다룬 도구·과제 안의 이해와 실행에 초점을 둔 연구가 있음처음 보는 이미지 분류 과제를 주평가로 사용. 여건이 되면 음성인식을 보조 전이 과제로 추가하고, 힌트 제공 전의 자발적 시험을 별도로 기록.
증강의 의미 구분증강으로 모델 정확도를 높이는 것은 학습자의 비판적 사고 향상과 다른 결과증강을 넣는다면 ‘어떤 변환이 현실 조건을 대표하는가’에 대한 학생의 선택·근거를 기록. 원본 단위로 학습/시험을 나눈 후 학습자료만 증강해 자료 누출 방지. 증강 유무와 교수전략을 동시에 바꾸지 않음.

실행 가능한 연구안

가제: 티처블 머신 기반 테스트 자료 설계 활동이 초등학생의 AI 모델 검증 수행에 미치는 영향

  • 연구 질문 1: 학습자료 개선 활동과 비교하여 테스트 자료 설계 활동이 새로운 모델의 오류 발견·근거 설명·판단 수정에 차이를 만드는가?
  • 연구 질문 2: 수행의 차이는 어떤 시험 전략과 활동 과정에서 나타나는가?
  • 선택적 확장: 습득한 검증 전략이 음성인식 등 다른 AI 과제에서도 자발적으로 나타나는가? 첫 발표에서는 주성과와 분리하여 탐색적으로 다룬다.
  • 대상: 접근 가능한 초등 고학년 학급. 필요한 표본은 기대 효과·분석 방법·학급 수를 고려해 결정하며 임의의 인원만으로 충분하다고 단정하지 않는다.
  • 절차: 사전 수행평가 → 동일한 티처블 머신 기초학습 → 조건별 활동 → 새로운 공통 모델의 사후 수행평가 → 일부 학생 면담. 여건이 되면 지연검사 추가.
  • 조건 통제: 교사·수업시간·초기 데이터·모델·기기·시험 기회를 최대한 동일하게 둔다. 학급별 처치라면 학급 차이와 처치가 섞이는 문제를 고려한다. 한 학급씩만 비교할 경우 인과효과 주장을 제한한다.
  • 분석: 사전 수준과 학급 구조를 고려한 집단 비교, 효과 크기와 불확실성 보고, 시험 로그·근거 설명의 질적 분석. 소규모 단일집단만 가능하면 과정 중심 탐색 연구로 설계한다.

발표에서 사용할 차별성 설명

선행연구는 티처블 머신을 활용한 제작과 성찰, 설명 시각화, 비판적 머신러닝 프로그램의 교육적 가능성을 보여주었다. 본 연구는 그중 ‘모델 검증’에 초점을 두고, 학습자료 개선 활동과 테스트 자료 설계 활동을 구분하여 비교하고자 한다. 학생이 수업에서 만들지 않은 공통 모델을 검증하도록 함으로써, 모델 제작 성과와 구별되는 오류 발견·증거 설명·판단 수정 수행을 분석하고자 한다.

피할 주장: ‘티처블 머신과 비판적 사고를 연결한 최초 연구’, ‘오류 찾기를 처음 도입’, ‘정확도 향상이 곧 비판적 사고 향상’. 차별성은 도구나 활동의 존재보다 비교 조건·평가 과제·검증 과정의 분석에 둔다.
